# Stormworks-Reference

> **サンドボックス建造ゲーム Stormworks: Build and Rescue の部品仕様をまとめた資料集。**
> 扱うのは**ゲーム内のマイクロコントローラ部品の中で動く Lua** と、**ゲームのビークル保存XML** だけ。
> 「レーダー」「ミサイル」などの部品名はすべて**ゲームがそう名付けた仮想部品の名前**であり、
> 記録してあるのは**そのゲーム部品の挙動をゲーム内で測った結果**である。実世界の対応物は無い
> (全文は [`_disclaimer_weapons_terms.md`](_disclaimer_weapons_terms.md))。

公式Wiki・コミュニティ資料・ゲームの定義ファイルの調査結果に、作者が実機(ゲーム内)で確かめた事実を足したもの。
web の情報と実機が食い違う箇所は実機を優先している。

## 読むときの注意

- **本文中の `Obj NNNN 略称` は作者のプロジェクト番号**で、その事実をどこで実測したかを示す。
  各プロジェクトの設計記録は公開していない(一覧は [`09_conventions.md`](09_conventions.md) §10)
- 本文中の「ユーザー」は作者を指す
- 「【実機検証済み】」「【一次資料で確認済み】」の無い記述は web 資料からの引用。**「未検証」「推定」と書いたものは推定のまま**
- 元は AI エージェントに読ませるための資料なので、散文の体裁より密度を優先している
- ゲームの更新で変わりうる。確認した日付を書いてある項目は、その日時点の挙動
